# 鉴见小程序「我的 / 个人主页」页面技术规格书

> 基准文件：`jianjian-profile/index.html`（407 行，当前定稿）
> 用途：据此一比一复刻该页面（HTML/CSS 原型 → 小程序原生 WXML/WXSS 或任意前端框架）。
> 文档中所有色值、字号、尺寸、文案均直接取自基准文件，未做二次发挥。

---

## 1. 技术约束

| 项 | 规格 |
|---|---|
| 文件形态 | 单文件 HTML，CSS 内联于 `<head><style>`，JS 内联于 `</body>` 前 |
| 语言 | ES5 语法（无箭头函数、无 `let/const`、无模块化） |
| 外部依赖 | **无**。无外部字体、无 CSS 框架、无第三方 JS 库 |
| 图标方案 | 内联 SVG（自绘线性图标），无图标字体、无图片文件 |
| 视口 | `<meta name="viewport" content="width=device-width, initial-scale=1" />` |
| 编码 | UTF-8，`lang="zh-CN"` |
| 演示容器 | `.phone` 固定 `390 × 844`，超出部分在 `.scroll` 内滚动 |
| 页面标题 | `鉴见小程序 · 我的页 · 高保真原型` |

**注意**：`.toolbar`（角色切换）与 `.legend`（设计说明卡）位于手机框外，是**原型演示辅助层**，不属于产品页面本身；复刻真实页面时应剔除。

## 10. 交互行为

| 触发 | 行为 |
|---|---|
| 顶部角色切换按钮 | 切换检测师/管理员状态，见第 9 节 |
| `?role=admin` | 页面加载后自动触发管理员切换（代码在事件绑定之后执行，顺序不可颠倒） |
| `?scroll=bottom` | 将 `.scroll.scrollTop` 设为 2000，直达页面底部 |
| 返回箭头 / 齿轮设置 / 角色与权限 / 双按钮 / 反馈 / 退出 / 各 tab | 均调用 `toast(msg)` 给出轻提示，1400ms 消失 |
| 列表项 `:active` | 背景切换为 `var(--canvas)`，提供点按反馈 |

**顺序要求**：URL 参数处理代码必须写在 `rbInspector.onclick` / `rbAdmin.onclick` 赋值之后，否则自动点击无效（此前踩过坑）。

## 13. 落地小程序映射建议

| 原型元素 | 小程序实现 |
|---|---|
| `.phone / .statusbar / .navbar` | 页面容器 + 自定义导航（或 `navigationStyle:custom`） |
| `.scroll` | `<scroll-view scroll-y>`，高度 `calc(100vh - navHeight - tabbarHeight)` |
| `.identity / .stats / .section` | `<view>` + WXSS，样式值可直接平移（px→rpx 按设计稿基准换算） |
| `.admin-actions / #adminSection` | `wx:if="{{isOrgAdmin}}"` 控制，服务端权限二次校验 |
| `.tabbar` | `app.json` 原生 tabBar（4 项） |
| `toast(msg)` | `wx.showToast({title:msg,icon:'none',duration:1400})` |
| URL 参数 | `onLoad(options)` 读 `options.role` / `options.scroll` |
| 内联 SVG | 转 base64 背景图、iconfont 或小程序 `<image>` 资源 |
| 字体族 | 小程序端用系统字体栈，等宽场合同样用 `ui-monospace,monospace` |
