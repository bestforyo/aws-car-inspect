# 鉴见小程序「我的 / 个人主页」字体清单

> 基准文件：`jianjian-profile/index.html`（当前定稿）
> 全部取自该文件实际声明，均为系统字体，**无外部字体文件**。可直接贴入文档。

---

## 一、字体族（3 种用法）

| 类型 | 字体栈 | 应用元素 |
|---|---|---|
| 正文（默认） | `-apple-system, BlinkMacSystemFont, "PingFang SC", "Microsoft YaHei", sans-serif` | `body` 及绝大多数元素继承 |
| 等宽 | `ui-monospace, monospace` | `.id-code`（工号）、`.order-meta`（订单编号，样式保留但当前无内容） |
| 继承覆盖 | `font-family:inherit` | `.role-switch button`（角色切换按钮，显式声明继承） |

---

## 二、全局基线

`body`：`font-size: 14px` · `line-height: 1.5` · `color: var(--text)` = `#23343E`

未单独声明字号的组件均继承 14px；未单独声明字重的均为 400。

## 五、字间距（letter-spacing）

| 值 | 元素 | 用途 |
|---|---|---|
| `1px` | `.id-code` | 等宽工号 `INSPECTOR · ID 0286` 拉开字符，增强编号感 |
| `0.5px` | `.navbar .nav-title`、`.version` | 标题与版本号的轻微透气 |
| `-0.5px` | `.stat .num` | 26px 大数字收紧，避免松散 |

## 七、颜色与字体的组合要点

| 场景 | 色值 |
|---|---|
| 主文字 | `--text #23343E`、深墨 `--brand-900 #172E39` |
| 次要文字 | `--muted #8D999C`、`.id-role #5E7069`、`.stat .label #54645E`、`.org-line #7A8A83` |
| 深底反白 | 状态栏/导航栏 `#fff`；头像 `#fff`；机构 Logo `--accent #D7ED9F` |
| 强调 | 成功绿 `--success #64866D`（已认证、趋势）；警示 `--warning #BD8851`（管理员标识）；退出 `--return #C87861` |
| 浅底徽章文字 | `.badge #4E6159`、`.badge.verify --primary-deep #264C40` |

## 八、复刻 / 落地注意点

1. **等宽只用于编号类**：`.id-code` 用 `ui-monospace, monospace` + `1px` 字间距；正文不要误用等宽。
2. **统计数字用负字间距**：`.stat .num` 的 `-0.5px` 是 26px 大数字紧凑观感的关键，别漏。
3. **头像与机构 Logo 是单字大字**：分别 26px/600 与 20px/600，字体族继承系统栈，不是图标。
4. **最小字号为 9px**（`.qitem .qsub`）。若落地小程序需提升可读性，可上调至 10–11px，但会与设计稿产生细微差异，需权衡。
5. **字重层级**：全页只用 400/500/600/700 四档，其中 700 仅两处（姓名、统计数字），不可随意加重。
6. **内联样式**：工具条 ` / 390×844` 为 `color:#BCC6C1` 内联覆盖（继承 12px）；「管理员」标识为 `style="color:var(--warning)"` 内联覆盖（继承 11px）——两者属于原型辅助层，产品页可剔除。
7. **小程序适配**：系统字体栈可直接平移；`ui-monospace` 在 iOS/Android 均可用；如改用 rpx，字号需按设计稿基准统一换算，不要逐项手调。
