# 鉴见小程序「首页」页面技术规格书

> 基准文件：`jianjian-home/index.html`（281 行，当前定稿）
> 配套资源：`assets/car_alpha.png`、`assets/moto_alpha.png`（透明底逼真车图）
> 用途：据此一比一复刻首页（HTML/CSS 原型 → 小程序原生 WXML/WXSS 或任意前端框架）。
> 本文所有色值、字号、尺寸、文案均直接取自基准文件，未做二次发挥。文末附落地风险提示与 dev/prod 建议。

---

## 1. 技术约束

| 项 | 规格 |
|---|---|
| 文件形态 | 单文件 HTML，CSS 内联于 `<head><style>`，JS 内联于 `</body>` 前 |
| 语言 | ES5 语法（无箭头函数、无 `let/const`、无模块化） |
| 外部依赖 | **无 CSS 框架、无第三方 JS、无外部字体**。图标为内联 SVG；车辆插图为本地 PNG |
| 视口 | `<meta name="viewport" content="width=device-width, initial-scale=1" />` |
| 编码 | UTF-8，`lang="zh-CN"` |
| 演示容器 | `.phone` 固定 `390 × 844`，内容在 `.scroll` 内滚动 |
| 页面标题 | `鉴见小程序 · 首页 · 高保真原型` |

**注意**：`.toolbar`（原型工具条）与 `.legend`（设计说明卡）位于手机框外，属于**原型演示辅助层**，产品页面应剔除。

## 2. 设计令牌（CSS 变量）

定义于 `:root`，共 14 个：

```css
:root{
  --brand-900:#172E39;  /* 深墨：标题、数字、主文字 */

  --primary:#376D57;    /* 主绿：进度条、激活态、图标 */
  --primary-deep:#264C40; /* 主绿深阶：标签/入口文字 */
  --accent:#D7ED9F;     /* 青柠：数据数字、光晕、火花 */
  --canvas:#F5F7F5;     /* 浅灰绿画布 */

  --text:#23343E;       /* 正文主色 */
  --muted:#8D999C;      /* 次要文字 */
  --line:#E9EDEB;       /* 边框/分隔线 */
  --success:#64866D;    /* 成功/进行中绿 */
  --success-bg:#EAF5EF; /* 成功浅底（进行中标签、待审核条块） */
```

**基础重置**：`*{box-sizing:border-box;margin:0;padding:0;-webkit-tap-highlight-color:transparent}`

处理要点（复刻/再生成时注意）：
1. 生成原图带右下角「AI生成 / WORKBUDDY」水印，已通过裁剪去除；不可直接使用原生成图。
2. 原生成背景为棋盘格纹理，已用 canvas 连通区域填充（从四角扩散、亮度 >205 且低饱和判为背景）抠成透明；车身高光仍需人工目检。
3. CSS 用 `object-fit:contain;object-position:right bottom` + `.entry-shade` 左侧渐隐遮罩融合；**不要**改用 `mix-blend-mode:multiply`（透明底会失效）。

## 11. 小程序落地映射与风险提示

| 原型元素 | 小程序实现 |
|---|---|
| `.phone / .statusbar` | 页面容器 + 原生状态栏（自定义导航时自行绘制） |
| `.scroll` | `<scroll-view scroll-y>`，高度按实际导航栏重算 |
| `.hero / .entries / .work` | `<view>` + WXSS，样式值按设计稿基准换算 rpx |
| `.entry-img` | 本地资源入包（建议放 `assets/` 或云存储 CDN） |
| `.work-more` | `<view bindtap>` → `wx.navigateTo` 审核页 |
| `.tabbar` | `app.json` 原生 tabBar（4 项，与现有配置一致） |
| `toast(msg)` | `wx.showToast({title:msg,icon:'none',duration:1400})` |
| `?scroll=bottom` | `onLoad(options)` 读参数并 `wx.pageScrollTo` |
| 内联 SVG | 转 base64 背景图 / iconfont / `<image>` 资源 |

**风险提示与常见坑**
1. **图片体积**：两张透明 PNG 合计约 1.6MB，主包有 2MB 限制风险；落地建议上传云存储走 CDN，或压缩为 WebP。
2. **rpx 换算**：以 390px 设计稿为基准时 1px ≈ 2.08rpx（按 750rpx 宽），不要逐项手调导致比例失真。
3. **安全区**：真机底部有 Home Indicator，tabbar 需加 `env(safe-area-inset-bottom)` 或小程序 `safe-area` 适配，否则被遮挡。
4. **数据兜底**：演示数值全部写死，接真实接口时务必给默认值，避免首屏 `undefined`/空白。
5. **权限**：待审核入口按角色显示；检测师与机构管理员可见性不同，前端隐藏不能替代服务端鉴权。
6. **dev/prod**：dev 可用 toast 占位验证交互；prod 必须换成真实跳转与人脸/权限校验，且移除 `.toolbar`/`.legend` 原型层。
