# 鉴见小程序 · 检测订单页 技术规格书

> 依据 `jianjian-orders/index.html`（定稿，438 行）逐项提取，供一比一复刻与小程序落地使用。
> 生成日期：2026-11-25

---

## 1. 概述与技术约束

| 项 | 规格 |
|---|---|
| 形态 | 单文件高保真可交互原型（HTML + 内联 CSS + 内联 JS） |
| 语言 | HTML5 / CSS3 / ES5（无箭头函数、无 `let/const`、无模块化） |
| 外部依赖 | **无**（无 CDN、无框架、无字体文件、无图标库） |
| 图标 | 全部内联 SVG（`<svg>` + `<path>`），无图标字体 |
| 图片 | 2 张透明底 PNG 实拍图（`assets/` 本地目录） |
| 演示容器 | 桌面预览用 390×844 手机框，滚动区 `calc(844px - 44px - 64px) = 736px` |
| 交互演示 | 触摸事件 + 鼠标拖拽双通道，便于桌面预览验证拨动手势 |

**原型辅助层（产品页落地时剔除）**：`.toolbar`（顶部说明条）、`.legend`（底部设计要点卡）仅用于原型讲解，不属于产品界面。

```js
  inspector:'林师傅',       // 检测师

  stLabel:'待检测',         // 状态显示名
  act:'开始检测'            // 操作文案

```

### 9.2 状态映射

```js
FILTERS   = ['全部','待检测','检测中','待审核','待修改','已完成'];
ST2FILTER = { wait:'待检测', doing:'检测中', review:'待审核', fix:'待修改', done:'已完成' };
ST_DOT    = { '全部':'--primary', '待检测':'--st-wait', '检测中':'--st-doing',
              '待审核':'--st-review', '待修改':'--st-fix', '已完成':'--st-done' };
current   = '全部';  // 当前筛选状态
```

状态键 ↔ 显示名 ↔ 颜色三者需保持一致；新增状态时三处映射同步扩展。

## 10. 交互行为

| 交互 | 触发 | 行为 |
|---|---|---|
| 打开弹层 | 点 `.state-btn` | `openSheet()`：渲染选项 + 遮罩淡入 + 面板上滑 + 箭头旋转 |
| 关闭弹层 | 点选项 /「完成」/ 遮罩 | `closeSheet(e)`（含 `stopPropagation` 防冒泡）；选项同时触发筛选 |
| 弹层选状态 | 点 `.sheet-opt` | `pickFilter(el)` → 关闭弹层 → `applyFilter` → Toast「状态：X」 |
| 拨动切换 | 列表左右滑 | 左滑=下一状态、右滑=上一状态；阈值 `|dx|≥45 且 |dx|≥|dy|×1.2` |
| 防误触 | 拨动后 | `dragMoved` 抑制卡片点击 60ms；无效斜滑/小幅滑动不触发 |
| 边界提示 | 到首/末状态继续拨 | Toast「已是第一个/最后一个状态」 |
| 列表动画 | 切换状态 | `.slide-in` + `cardIn`，方向 `--dir`（prev=-18px / next=18px），四卡错峰 40ms |
| 卡片点击 | 点 `.card` | Toast「打开订单：{车型}」（原型占位，落地跳详情） |
| URL 预设 | `?filter=待检测` | 初始化后设 current 并重渲染；`?scroll=bottom` 滚到底 |

> 落地注意：`URL 参数处理` 必须写在事件绑定之后；`applyFilter` 中 `void listEl.offsetWidth` 强制重排以重放 CSS 动画，不可省略。

## 13. 小程序落地映射与风险提示（栈师视角）

### 13.1 结构映射

| 原型 | 微信小程序 |
|---|---|
| `.phone` / `.scroll` | 页面根 + `scroll-view`（或整页滚动） |
| `.state-btn` + `.sheet-mask` | 自定义按钮 + 自定义弹出层 / `van-popup`（若用 Vant） |
| `.card` × N | `wx:for` 列表项，绑定 `data-id` |
| 内联 SVG | 转 base64 背景图或 iconfont（小程序不支持内联 `<svg>` 渲染） |
| `toast()` | `wx.showToast` |
| 拨动 `touchstart/touchend` | `bindtouchstart` / `bindtouchend`（保留 mouse 事件仅用于原型） |

### 13.2 数据接入

现有工程 `pages/orders/orders.js` 已有 `services/data.js` 的 `listOrders(status)` 与状态映射 `utils/util.js statusOf()`。落地时：
- 用真实接口替换 `ORDERS` 演示数组；
- `countOf()` 数量改为后端聚合字段（如 `counts`），避免前端拉全量统计；
- `act` 文案由 `status` 在 WXML 内通过 `wxs` 或 JS 映射，不写死在数据中。

### 13.3 风险提示

| 风险 | 说明 | 建议 |
|---|---|---|
| 主包体积 | 两张 PNG 约 1.6MB，接近 2MB 主包上限 | 压缩 WebP / 走云存储 URL / 放分包 |
| 内联 SVG | 小程序 WXML 不支持内联 `<svg>` | 改 base64 背景或 iconfont |
| 手势冲突 | 列表拨动与页面横向滚动/侧滑返回可能冲突 | 限制在列表区域、阈值判定；真机测试 |
| 空状态数量 | 待审核 0 单时弹层仍显示该项（合理，提示无单） | 保持显示，勿隐藏状态项 |

### 13.4 dev / prod 建议

- **dev**：保留 `?filter=` URL 预设与 Toast 占位，方便联调；车图用本地 `assets/`。
- **prod**：移除 URL 调试参数；车图走 CDN/云存储；Toast 换真实跳转（`REVIEW_PENDING`/`PUBLISHED` → 审核详情，其余 → 检测页）；接入埋点记录筛选与拨动使用率。
