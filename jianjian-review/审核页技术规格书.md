# 鉴见小程序 · 审核页 技术规格书

> 依据 `jianjian-review/index.html`（定稿，514 行）逐项提取，供一比一复刻与小程序落地使用。
> 生成日期：2026-11-25

## 1. 概述与技术约束

| 项 | 规格 |
|---|---|
| 形态 | 单文件高保真可交互原型（HTML + 内联 CSS + 内联 JS） |
| 语言 | HTML5 / CSS3 / ES5（无箭头函数、无 `let/const`、无模块化） |
| 外部依赖 | **无**（无 CDN、无框架、无字体文件、无图标库） |
| 图标 | 全部内联 SVG（`<svg>` + `<path>`），无图标字体 |
| 图片 | 2 张透明底 PNG 实拍图（`assets/` 本地目录） |
| 演示容器 | 桌面预览用 390×844 手机框，滚动区 `calc(844px - 44px - 64px) = 736px` |
| 交互演示 | 触摸事件 + 鼠标拖拽双通道，便于桌面预览验证拨动手势 |
| 双角色 | 顶部工具条切换「检测师 / 机构管理员」，同一页面呈现两套文案与操作 |

**原型辅助层（产品页落地时剔除）**：`.toolbar`（顶部说明条 + 角色切换）、`.legend`（底部设计要点卡）仅用于原型讲解，不属于产品界面；其中角色切换在产品中应由登录身份驱动。

## 3. 全局重置与基线

```css
*{box-sizing:border-box;margin:0;padding:0;-webkit-tap-highlight-color:transparent}
.hidden{display:none !important}
body{font-family:-apple-system,BlinkMacSystemFont,"PingFang SC","Microsoft YaHei",sans-serif;
  background:#E9EEEA;color:var(--text);font-size:14px;line-height:1.5;
  min-height:100vh;display:flex;flex-direction:column;align-items:center;padding:24px 16px 48px}
```

- 全局 `box-sizing:border-box`，零外/内边距，禁用移动端点击高亮。
- `.hidden{display:none !important}`：强制隐藏类，`!important` 防止被 `.subtabs{display:flex}` 一类规则覆盖（历史修复点）。
- 正文基线：14px / 行高 1.5 / 色值 `#23343E`。

### 9.2 状态映射

```js
FILTERS   = ['全部','待审核','审核中','待修改','已完成','已发布'];
ST2FILTER = { wait:'待审核', review:'审核中', fix:'待修改', done:'已完成', published:'已发布' };

```

## 10. 交互行为

### 10.1 角色切换

| 触发 | 行为 |
|---|---|
| 点「检测师」/「机构管理员」 | `applyRole()` 更新眉标、标题、副标题、列表标题、底部说明，并调用 `renderStateBtn()` + `renderList()`；弹出 Toast「已切换：X」 |
| URL `?role=admin` | 初始化后自动点击管理员按钮（须在事件绑定与初始渲染之后执行） |

### 10.2 状态筛选

| 交互 | 触发 | 行为 |
|---|---|---|
| 打开弹层 | 点 `.state-btn` | `openSheet()`：渲染选项 + 遮罩淡入 + 面板上滑 + 箭头旋转 |
| 关闭弹层 | 点选项 /「完成」/ 遮罩 | `closeSheet(e)`（含 `stopPropagation` 防冒泡）；选项同时触发筛选 |
| 弹层选状态 | 点 `.sheet-opt` | `pickFilter(el)` → 关闭弹层 → `applyFilter` → Toast「状态：X」 |
| 拨动切换 | 列表左右滑 | 左滑=下一状态、右滑=上一状态；阈值 `|dx|≥45 且 |dx|≥|dy|×1.2` |
| 防误触 | 拨动后 | `dragMoved` 抑制卡片点击 60ms；无效斜滑/小幅滑动不触发 |
| 边界提示 | 到首/末状态继续拨 | Toast「已是第一个/最后一个状态」 |
| 列表动画 | 切换状态 | `.slide-in` + `cardIn`，方向 `--dir`（prev=-18px / next=18px），最多 4 卡错峰 40ms |
| 卡片点击 | 点 `.card` | `openReview()`：非拨动时 Toast「打开：{车型}」（原型占位，落地跳详情） |
| URL 预设 | `?filter=待审核` | 初始化后设 current 并重渲染；`?scroll=bottom` 滚到底 |

> 落地注意：`URL 参数处理` 必须写在事件绑定之后；`applyFilter` 中 `void listEl.offsetWidth` 强制重排以重放 CSS 动画，不可省略。

## 13. 小程序落地映射与风险提示（栈师视角）

### 13.1 结构映射

| 原型 | 微信小程序 |
|---|---|
| `.phone` / `.scroll` | 页面根 + `scroll-view`（或整页滚动） |
| `.toolbar .seg` 角色切换 | 由登录态/机构成员角色决定，不暴露切换器 |
| `.state-btn` + `.sheet-mask` | 自定义按钮 + 自定义弹出层 / `van-popup`（若用 Vant） |
| `.card` × N | `wx:for` 列表项，绑定 `data-id` |
| 内联 SVG | 转 base64 背景图或 iconfont（小程序不支持内联 `<svg>` 渲染） |
| `toast()` | `wx.showToast` |
| 拨动 `touchstart/touchend` | `bindtouchstart` / `bindtouchend`（保留 mouse 事件仅用于原型） |

### 13.2 数据接入

现有工程 `pages/review/`、`pages/review-detail/` 及 `services/data.js` 已有审核相关能力。落地时：
- 用真实接口替换 `REVIEWS` 演示数组；
- `countOf()` 数量改为后端聚合字段（如 `counts`），避免前端拉全量统计；
- 角色文案（`applyRole`）改为读取登录后角色（`is_org_admin()`），不在前端切换；
- `actLabel` 的操作与 `approve(orderId, revisionId, revision)` 等审核动作对接；
- 状态文案映射统一到 `utils/util.js`，避免与订单页 `statusOf()` 语义混用。

### 13.3 风险提示

| 风险 | 说明 | 建议 |
|---|---|---|
| 主包体积 | 两张 PNG 约 1.6MB，接近 2MB 主包上限 | 压缩 WebP / 走云存储 URL / 放分包 |
| 内联 SVG | 小程序 WXML 不支持内联 `<svg>` | 改 base64 背景或 iconfont |
| 手势冲突 | 列表拨动与页面横向滚动/侧滑返回冲突 | 限制在列表区域、阈值判定，真机测试 |
| 状态语义复用 | 与订单页同名变量含义不同（wait/doing/review） | 审核页独立映射表，勿直接复用订单页 |
| 权限边界 | 前端隐藏管理员操作不等于鉴权 | 审核动作服务端校验 `is_org_admin()` + RLS |

### 13.4 dev / prod 建议

- **dev**：保留 `?role=admin` / `?filter=` URL 预设与 Toast 占位，方便联调；车图用本地 `assets/`。
- **prod**：移除 URL 调试参数；角色由登录态驱动；车图走 CDN/云存储；卡片点击跳真实审核详情（`openReview` → `REVIEW_PENDING` 详情），接入埋点记录筛选、拨动、角色使用率。
