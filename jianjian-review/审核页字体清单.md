## 八、复刻注意点（9 条）

1. **字体栈顺序**：`-apple-system` → `BlinkMacSystemFont` → `"PingFang SC"` → `"Microsoft YaHei"` → `sans-serif`，保证 iOS/安卓/桌面回退一致。
2. **等宽仅一处**：审核编号 `.no` 用 `ui-monospace, monospace`，与正文区分便于逐位核对（订单页另有车牌也用等宽，本页无车牌字段）。
3. **按钮字体**：`.state-btn` 必须 `font-family:inherit`，否则在部分浏览器回退成系统 UI 字体。
4. **最小字号 8px**：`.sec .st .en`（REVIEW）为英文装饰标签；唯一低于 9px 的元素，一比一复刻时保留。
5. **箭头字符**：拨动提示的 `‹` `›` 是 Unicode 字符（16px），非 SVG，渲染依赖系统字体，不同平台字形略有差异。
6. **`<b>` 标签默认粗体**：`.toolbar .tt b`（13px）与 `<b id="swipePos">` 未显式声明字重，靠浏览器默认 700；`.swipe-hint b` 显式 600 覆盖了默认值；如需精确控制应统一显式写 `font-weight`。
7. **状态徽章 10px/500**：比订单页（600）更轻，配合「前景色+浅底+文字标签」三重编码保证可辨识。
8. **车型名 13px/600**：比订单页（14px/700）更小更轻，为状态徽章让出卡片主行空间。
9. **无外部字体**：全页零 `@font-face`、零 CDN 字体，离线可用；落地小程序时直接使用系统字体栈即可，不要引入 Web 字体增加包体。
