设计要点（参考图 → 小程序）

  • 顶部横幅桌面标题区收敛为深青绿横幅：眉标 + 审核进度 + 副标题 + 同心圆装饰；三项审核数据直接放横幅，一眼可见。
  • 状态切换与检测订单页一致：顶部状态大按钮（当前状态+数量+箭头）点击弹出底部面板，6 状态每项带彩点+数量+勾选；也可在列表上左右拨动切换，带滑入动画。
  • 列表桌面三列表格收敛为卡片：逼真车图 + 车型 + 状态徽章 + 编号 + 套餐 + 时间 + 下一步动作；切换状态即切换对应列表。
  • 状态色待审核=琥珀、审核中=紫、已发布=蓝、已完成=绿、待修改=玫红，均带文字标签，不单靠颜色传达。
  • 双角色检测师看「审核进度」；机构管理员为「审核中心」，待审核卡操作显示「去审核」。
  • 一致性沿用鉴见深青绿横幅与全套 token，与首页/订单/我的视觉语言统一。
